# Project Overview

## Purpose

The Tech-John portfolio is a personal branding website for **John Gitau**, a Full Stack Developer. It is designed to showcase skills, professional experience, completed projects, and client work.

## Goals

- Present a clean, modern portfolio landing page.
- Showcase project case studies and client work.
- Provide an easy way for visitors to contact the developer.
- Offer a responsive design that works across desktops, tablets, and mobile devices.

## Key Features

- Hero section with clear branding and call-to-action buttons.
- About section with experience, education, and professional summary.
- Project showcase section with cards for portfolio pieces.
- Client testimonials section linking to live projects.
- Contact area with a submission form powered by EmailJS.
- Toast notification system for form validation and feedback.
- Responsive design and accessibility improvements.

## Live Demo

Live deployment is available at:

- https://jonterob.github.io/Tech-John/

## Notes

This project is built as a static website with progressive enhancement through JavaScript and external services. It uses preloaded assets and deferred styles to improve load performance.
